# Curriculum — Week by Week

## Phase 0: Mindset (Before Code)

**Goal:** Understand that programs are instructions stored as numbers, executed by hardware.

| Day | Theory | Activity |
|-----|--------|----------|
| 1 | 01 How Computers Work, 02 Binary | Draw a CPU + RAM diagram |
| 2 | 03 Memory, 04 RAM, 05 CPU | Label address bus, data bus |
| 3 | 06 Compilation, 07 GCC | Compile `hello.c`, inspect object file |
| 4 | 08 Headers, 09 Libraries | Trace `#include` expansion |
| 5 | 10–14 Variables, Types, ASCII, Strings | ASCII table quiz |

## Theory Completion Checklist

Before starting each module, verify:

- [ ] **C00:** Theory 01–14, 23, 43–45

- [ ] **C06:** Theory 26 (argc/argv)
- [ ] **C07:** Theory 27–33 (Heap)

- [ ] **C11:** Theory 41, 43–46
