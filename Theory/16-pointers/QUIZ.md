## Multiple Choice


### MCQ 1
A pointer stores:

- A) A memory address  
- B) Always the value 42  
- C) A file name  
- D) CPU speed  

**Answer: A**

### MCQ 2
&x gives:

- A) Address of x  
- B) Value of x  
- C) Size of x  
- D) Type of x  

**Answer: A**

### MCQ 3
*p when p is int* means:

- A) Dereference — value at address  
- B) Multiply p  
- C) Pointer to pointer only  
- D) Error always  

**Answer: A**
